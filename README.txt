VIOOL LESSEN
============

WAT ZIT ER IN DEZE MAP
- index.html            -> de app zelf
- Lesson1 ... Lesson5     -> zet hier de video's van elke les in

Video's toevoegen
- Hernoem in elke LessonX-map je .mov bestanden naar 1.mov, 2.mov, 3.mov, enzovoort, in de volgorde waarin ze moeten verschijnen
- Pas het getal "count" aan bovenaan in index.html als er meer/minder lessen zijn.
- Bestanden groter dan 25MB toevoegen via de Terminal (max. 100MB)
   * zie: https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository#adding-a-file-to-a-repository-using-the-command-line
   * eerst clone maken op pc
   * dan stappen van deze link volgen
   * gebruikersnaam github ingeven (bart-dewulf)
   * personal passcode gebruiken (ipv wachtwoord), zie github-settings-developer-passcode
